Cypress Automation Testing

Deskripsi Project

Project ini merupakan tugas Automation Testing menggunakan Cypress yang bertujuan untuk menerapkan pengujian otomatis pada UI website dan API.

Pada project ini digunakan beberapa konsep utama, yaitu:
1. UI Automation Testing dilakukan untuk mengotomatisasi interaksi pengguna pada website.
2. Intercept untuk memonitor dan memvalidasi request serta response API yang terjadi ketika user berinteraksi dengan aplikasi.
3. Page Object Model (POM) untuk membuat struktur script automation yang lebih rapi dan mudah digunakan kembali.
4. API Automation Testing untuk melakukan pengujian endpoint API.

Project ini dibuat sebagai latihan untuk memahami penerapan automation testing dari sisi UI dan API, serta meningkatkan kemampuan dalam membuat test case yang terstruktur.
